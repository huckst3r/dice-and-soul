# dice-and-soul

Минимальный text RPG engine на Python с комнатами и dice mechanics.

## Структура

```text
engine/
  game.py
  world.py
  dice.py
  combat.py
  abilities.py
  classes.py
  player.py
  item.py
  npc.py
  quest.py
  narrative.py

world/
  rooms.py
  enemies.py
```

## Запуск

```bash
python3 rpg_engine.py
```

При старте новой игры движок предлагает выбрать класс: `warrior`, `rogue` или `mage` (можно вводить имя класса или номер `1/2/3`).
Также доступна отмена выбора через `0`/`cancel`.
Если найден `savegame.json`, можно загрузить существующее сохранение, и тогда класс берется из сейва.

## Команды

- `look` — осмотреть комнату
- `look <npc>` — осмотреть NPC в текущей комнате
- `talk <npc>` — поговорить с NPC (реплика зависит от памяти + случайная фраза)
- `help <npc>` — помочь NPC (влияет на память NPC)
- `go <direction>` — перейти (`north/south/east/west`, а также `secret/back` при открытии)
- `search` — поиск (бросок d6)
- `attack` — атака врага (попадание через d20 против defense, урон d6)
- `attack <npc>` — атаковать NPC (меняет отношение NPC)
- `take <item>` — поднять предмет из комнаты
- `drop <item>` — выбросить предмет в комнату
- `inventory` — показать инвентарь
- `equip <item>` — экипировать предмет из инвентаря
- `unequip <slot>` — снять предмет из слота (`weapon`, `armor`, `ring`)
- `equipment` — показать текущее снаряжение
- `quests` — показать принятые квесты
- `accept <quest>` — принять квест от NPC в текущей комнате
- `complete <quest>` — завершить квест при выполненной цели
- `use <ability> [target]` — применить способность (части способностей цель не требуют)
- `potion` — выпить зелье
- `save` — сохранить игру в `savegame.json`
- `load` — загрузить игру из `savegame.json`
- `status` — текущее состояние персонажа
- `quit` — выход

Алиасы:
- `n` → `go north`
- `s` → `go south`
- `e` → `go east`
- `w` → `go west`
- `i` → `inventory`

## Случайные события при перемещении

При каждом успешном `go` есть шанс на событие:
- встреча с врагом;
- находка предмета;
- обнаружение скрытой комнаты.

## Narrative

- Добавлена функция `describe_event(event_context)` для текстового описания событий.
- Сейчас она возвращает статические шаблоны, но интерфейс подготовлен для будущего вызова LLM.

## Атрибуты игрока

- У игрока есть характеристики: `STR`, `DEX`, `INT`, `CHA`.
- Они применяются как модификаторы бросков: атака/урон, уклонение от урона, поиск и случайные события при перемещении.
- Добавлена система уровней и опыта:
  - поля игрока `level` и `xp`;
  - опыт дается за убийство врагов и завершение квестов;
  - порог следующего уровня: `level * 100` XP (100, 200, 300, ...);
  - при повышении уровня увеличивается `max_hp`, полностью восстанавливается HP и случайно растет одна характеристика;
  - на некоторых уровнях класс может открыть новую способность.
- `status` показывает `level`, текущий XP до следующего уровня и HP в формате `current/max`.

## NPC

- В комнатах могут находиться несколько NPC.
- У каждого NPC есть память взаимодействий: количество разговоров, факт атаки, факт помощи.
- Команда `talk <npc>` учитывает память NPC: первое знакомство, более дружелюбный тон после нескольких разговоров, реакция на помощь/атаку.
- Команда `look <npc>` показывает описание NPC.
- Память NPC сохраняется и загружается через `save`/`load`.

## Quests

- Добавлен класс `Quest`: `name`, `description`, `objective`, `reward`, `status` (`active`/`completed`).
- NPC могут выдавать квесты (пример: `skeleton bounty` от `old guard` — убить скелета в крипте).
- Завершение квеста выдает награду предметом.
- Завершение квеста также дает XP.
- Прогресс квестов сохраняется/загружается через `save`/`load`.

## Procedural rooms

- Если при `go <direction>` нет заранее заданной комнаты, движок создаёт новую процедурную комнату.
- Сгенерированная комната получает случайные `name` и `description`, может содержать врага и/или предмет.
- Связи двусторонние: всегда создаётся обратный выход, чтобы можно было вернуться.
- Процедурные комнаты сохраняются в состоянии мира и восстанавливаются через `save`/`load`.
- Для новых комнат используется narrative-событие `describe_event({"type": "room_generated", ...})`.

## Parser examples

- `attack skeleton` → command: `attack`, args: `["skeleton"]`
- `take torch` → command: `take`, args: `["torch"]`
- `go north` → command: `go`, args: `["north"]`
- `look old guard` → command: `look`, args: `["old", "guard"]`

## Character classes

- Добавлен модуль `engine/classes.py` с классом `CharacterClass`.
- Классы:
  - `Warrior`: `STR +2`, способность `power_attack`
  - `Rogue`: `DEX +2`, способность `backstab`
  - `Mage`: `INT +2`, способность `firebolt`
- У игрока есть поле `character_class`, бонусы класса применяются при создании персонажа.
- `status` показывает класс и стартовые способности.
- Класс игрока сохраняется/загружается через `save`/`load`.

## Abilities

- Добавлен модуль `engine/abilities.py` с классом `Ability` (`name`, `description`, `cooldown`, `execute`).
- Способности:
  - Warrior: `power_attack`, `shield_block`, `whirlwind`
  - Rogue: `backstab`, `poison_strike`, `stealth_attack`
  - Mage: `firebolt`, `ice_shard`, `chain_lightning`
  - `power_attack` — сильный удар, `d8 + STR mod`
  - `shield_block` — снижает входящий урон от следующей атаки
  - `whirlwind` — атакует всех врагов в комнате
  - `backstab` — высокий урон при HP цели > 50%, `d10 + DEX mod`
  - `poison_strike` — урон и наложение яда
  - `stealth_attack` — бонусный урон по целям с HP > 50%
  - `firebolt` — магический удар, `d10 + INT mod`
  - `ice_shard` — урон с шансом оглушить
  - `chain_lightning` — урон по нескольким врагам
- Новая команда: `use <ability> [target]` (например, `use firebolt skeleton`, `use whirlwind`).
- Кулдауны способностей хранятся у игрока и отображаются в `status`.
- Кулдауны и класс персонажа сохраняются/загружаются через `save`/`load`.
- Также сохраняются/загружаются `level`, `xp`, `max_hp`, разблокированные способности и экипировка.


## Equipment

- Добавлен модуль `engine/equipment.py` с `EquipmentSlot`: `weapon`, `armor`, `ring`.
- Предметы (`Item`) могут иметь слот и бонусы к `STR`, `DEX`, `INT`, `HP`.
- Экипировка переносит предмет из инвентаря в слот, снимает бонусы предыдущего предмета слота и применяет бонусы нового.
- `status` и `equipment` показывают предметы по слотам и их бонусы.


## Status effects

- Добавлен модуль `engine/status_effects.py` с моделью `StatusEffect` (`name`, `duration`, `tick_effect`).
- У игрока и врагов есть список `active_effects`.
- В бою каждый ход эффекты тикают: наносят урон/влияние, уменьшают длительность и удаляются по завершении.
- Реализованы эффекты: `poison`, `burn`, `bleed`, `stun`.
- Способности и атаки некоторых врагов могут накладывать эффекты с вероятностью (включая `poison_strike`, `ice_shard`, `chain_lightning`).
- Активные эффекты сохраняются/загружаются через `save`/`load`.


## Bosses

- Добавлен класс `Boss`, расширяющий `Enemy` (модуль `world/enemies.py`).
- Боссы имеют повышенные HP, уникальные способности, уникальный лут и повышенную XP-награду.
- Примеры боссов: `Necromancer`, `Crypt Lord`, `Ancient Golem`.
- Боссы появляются в специальных комнатах (`forgotten_vault`, `obsidian_nexus`), могут появляться в процедурных комнатах и как событие после квеста `skeleton bounty`.
- При победе над боссом уникальный лут падает в текущую комнату.


## Factions

- Добавлен модуль `engine/factions.py` с фракциями: `guards`, `bandits`, `mages`, `merchants`, `cultists`.
- У NPC и врагов есть поле `faction`.
- У игрока хранится репутация по каждой фракции.
- Действия меняют репутацию:
  - `help <npc>` повышает репутацию фракции NPC
  - `attack <npc>` снижает репутацию фракции NPC
  - убийство врага снижает репутацию его фракции
- Репутация ограничена диапазоном `-100..+100`.
- Пороги репутации:
  - `friendly` при `>= +25`
  - `neutral` между `-24..+24`
  - `hostile` при `<= -25`
- Репутация влияет на:
  - дополнительные реплики и поведение NPC
  - доступность квестов (hostile-фракции отказывают)
  - бонусы за дружбу: friendly-фракции дают улучшенные квесты и подарки
  - враждебность и атаки при встрече (hostile NPC атакуют при входе в комнату)
  - враждебность случайных встреч с врагами фракции
- Репутация сохраняется и отображается в `status`.


## Loot tables

- Добавлен модуль `engine/loot.py` с `LootEntry` (`item_id`, `weight`) и `LootTable` (`roll()` по весам).
- У врагов поле `loot_table` заменяет фиксированные базовые дропы.
- При смерти врага выполняется бросок лут-таблицы и предмет появляется в текущей комнате.
- Пример таблицы для `Skeleton`:
  - `bones` (60)
  - `rusty_sword` (25)
  - `potion` (10)
  - `rare_ring` (5)
- Лут-таблицы сериализуются и корректно восстанавливаются при `save`/`load`.


## Procedural item generation

- Добавлен модуль `engine/item_generator.py` для процедурной генерации предметов по шаблону `prefix + base item + suffix`.
- Примеры: `Rusty Sword`, `Ancient Sword of Fire`, `Shadow Dagger of Venom`.
- Префиксы модифицируют характеристики: 
  - `Rusty` — снижает боевой бонус
  - `Ancient` — повышает боевой бонус
  - `Shadow` — повышает `DEX`
- Суффиксы добавляют эффекты/бонусы:
  - `of Fire` — шанс наложить `burn`
  - `of Venom` — шанс наложить `poison`
  - `of Giants` — бонус к `STR`
- Сгенерированные предметы полностью совместимы с инвентарем, экипировкой и `save`/`load`.


## Global events

- Добавлен модуль `engine/events.py` с `GameEvent` и `EventManager`.
- `EventManager` поддерживает:
  - `register(event_name, handler)`
  - `emit(event_name, context)`
- В движке добавлены базовые события:
  - `on_enter_room`
  - `on_enemy_killed`
  - `on_level_up`
  - `on_quest_completed`
- Системы игры теперь испускают события вместо прямого запуска части вторичной логики (дроп, XP за квест, реакции на вход в комнату и т.д.).
- Дополнительные подсистемы могут подписываться на эти события через `game.events.register(...)`.
